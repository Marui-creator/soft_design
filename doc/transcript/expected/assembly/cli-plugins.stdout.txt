svg> 文档：
  init [w] [h]
  read <file.svg>
  save [file.svg]
  canvas [w] [h]

图形编辑：
  create <type> <id> [params…] [in <containerId>]
  delete <id>
  move <id> <dx> <dy>
  scale <id> <factor>
  set <id> <attr> <value>
  group <newGid> <id1> <id2>…
  ungroup <gid>
  addto <gid> <id>
  front <id>
  back <id>

显示：
  tree [id]
  show <id>
  help
  stats
  dir

撤销重做：
  undo
  redo

支持的图形：rect、circle、ellipse、line、text、g。
带空格的参数请使用双引号包裹。
按 Ctrl+C 退出。
