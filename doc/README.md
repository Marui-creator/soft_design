# SVG 命令行编辑器实验

## 架构方案

### 模块划分
- cli：读取命令、解析参数、输出结果。
- commands：封装命令，管理撤销与重做。
- model：管理画布、图形和容器，提供统一操作。
- infrastructure：读取和保存 SVG 文件。

### 设计模式
- Command：每条编辑命令作为一个撤销、重做单元。
- Composite：容器和普通图形通过统一接口操作。

### 依赖方向
- cli 可以依赖 commands。
- commands 可以依赖 model。
- infrastructure 可以依赖 model。
- model 不依赖命令行和文件读写模块。
- 程序入口负责组装各模块。

### 变化点假设
- 后续可能增加图形类型。
- 后续可能增加图形界面。
- 后续可能更换文件读写方式。
- 具体扩展方式随实现补充。
